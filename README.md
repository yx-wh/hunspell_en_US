# en_US morphology dictionary for word-form lookup

Corrected and extended Hunspell morphology files for English, meant for
**word-form lookup** (lemma resolution) rather than plain spell checking:
look up `hoped` and get `hope`, look up `reconstructiveness` and get
`reconstruct`, look up `hopeful` and get `hope`.

Designed for [Ciyue](https://github.com/mumu-lhl/Ciyue)'s *Word-form lookup*
and for GoldenDict / GoldenDict-ng's morphology support. It also works as an
ordinary spell-checking dictionary, but that is not what it is tuned for.

## Files

| File | Description |
| --- | --- |
| `en_US.aff` | affix rules: upstream rules plus new derivation suffixes |
| `en_US.dic` | 174,422 entries |
| `en_US.txt` | upstream readme/provenance of *better morphologies 1.0* — **keep it**, it carries the license notices |

## Why this exists

The stock `en_US.dic` shipped by operating systems has no hand-written `st:`
entries, so irregular forms cannot be resolved to a lemma at all. The
"better morphologies 1.0" set from the GoldenDict project fixes that, but it
still carries stale suffix flags:

```
hop/SMDRG          # /D /G /R are wrong: these rules do not double the consonant
SFX D 0 ed [^ey]   # hop + ed  = hoped  (should be hopped)
SFX G 0 ing [^e]   # hop + ing = hoping (should be hopping)
```

Because of `hop/D`, both `hop` and `hope` are returned for `hoped` — which is
why "looking up *hoped* also shows *hop*" is such a common complaint.

## What changed

### Stage 1 — fixing wrong labels, adding derivations

- Removed **438 wrong flags on 212 base words** (D 148, G 154, R 111, T 24, Z 1).
  Genuine homographs were kept: `buss/D`, `psych/D,G`, `sky/D`, `putt/G`,
  `bath/D,G`, `sick/D`.
- Added missing stem links: `barred/barring → bar`, `cubbed/cubbing → cub`,
  `gapped/gapping → gap`, `snipped/snipping → snip`.
- `halved st:half` / `halving st:half` → `st:halve` (half is not a verb).
- `sky/R`, `sky/Z` moved to `ski/R`, so `skier → ski`.
- Added `googleable st:google`; the `google/DGSRZB` rule only produces `googlable`.
- Added **2,169 derivation labels on 2,001 entries** (`-al`, `-ity`, `-ic`,
  `-less`, `-ful`, `-ish`, `-ness`, `-ly`, `-ive`, `-ion`, `-ions`, `-ings`,
  `-ment`, `-ous`) — only when the derived word already exists as an entry, so
  no words are invented.
- The `-ic` suffix is tagged **`Q`**, not `c`: the upstream `.aff` already has
  `ONLYINCOMPOUND c`, and words tagged `c` disappear from the dictionary.

### Stage 2 — merging an ODE headword list

- 160,984 unique ODE entries: 16,941 compressed into tags, 104,229 added as
  entries. Total: **174,422 entries**, 866 KB → 2.1 MB.
- New suffixes/prefixes: `-ion`, `-ible`, `-or`, `-ist`, `-ism`, `-ize/-ise`,
  `-ship`, `-hood`, `-dom`, `-ward`, `-ify`, `-ate`, `-ary`, `non-`, `anti-`.
- `WORDCHARS` extended with `-` and `.`, so `ortho-axis` and `a.m.` match as a whole.

## Verification

Spot checks with `hunspell -s`:

| Query | Stems |
| --- | --- |
| `hoped` | `hope` (no longer `hop`) |
| `hopped` | `hop` |
| `hoping` / `hopping` | `hope` / `hop` |
| `barred` / `gapped` | `bar` / `gap` |
| `skier` | `ski` |
| `national` | `nation` |
| `hopeful` | `hope` |
| `googleable` / `googlable` | `google` |
| `personality` | `person` |

- Regression: all 155,082 upstream entries plus every form generated by the old
  `.aff` were fed to the old and the new dictionary — **0 new rejections**,
  18 additional forms accepted.
- ODE coverage: 159,744 collectable ODE words, **0 rejected**.
- Compression: 3,000 randomly sampled compressed pairs, all accepted.

Run the checklist in [`tests/cases.txt`](./tests/cases.txt):

```bash
hunspell -d ./en_US -s < /dev/stdin <<< "hoped"   # prints "hope"
```

## Known limitations

- Proper-noun `R`/`Z` flags were left untouched (`Arch/R → Archer`,
  `Berlin/Z → Berliners`); many of these may be intentional demonym links.
- Continuation classes on `-al` / `-ity` / `-ic` allow a few non-words
  (e.g. `aberrationality`); they only affect lookups of those exact strings.
- A few mechanical compressions are semantically wrong (`arty/Q → artic`,
  `cray/Q → craic`).
- 1,242 ODE combining-form entries (`acantho-`, `-acea`) are excluded; a few
  ODE entries containing slashes or special characters are not included.

## How to use

**Ciyue** — Settings → *Word-form lookup* → enable it → import this folder.
Then set the lookup mode to **Supplement** if you want the inflected form and
its lemma displayed side by side; **Fallback** only adds stems when nothing
matches exactly.

**GoldenDict / GoldenDict-ng** — point the morphology directory at this folder.

# 中文说明

## 这是什么

一份为「**词形还原**（查变形词回到原形）」而修订的英文 Hunspell 词典，适用于
[Ciyue](https://github.com/mumu-lhl/Ciyue) 的「词形还原」功能和
GoldenDict / GoldenDict-ng 的 morphology。查 `hoped` 得到 `hope`，查
`reconstructiveness` 得到 `reconstruct`，查 `hopeful` 得到 `hope`。

## 文件

| 文件 | 说明 |
| --- | --- |
| `en_US.aff` | 词缀规则：上游规则 + 新增派生后缀 |
| `en_US.dic` | 174,422 个词条 |
| `en_US.txt` | 上游 *better morphologies 1.0* 的说明与来源，**请保留**，里面有许可声明 |

## 为什么要改

系统自带的 `en_US.dic` 没有任何手写的 `st:` 条目，不规则变形根本无法回到原形。
GoldenDict 项目的 *better morphologies 1.0* 补上了这部分，但仍留着错误的标签：

```
hop/SMDRG          # /D /G /R 都是错的：这套规则不做辅音双写
SFX D 0 ed [^ey]   # hop + ed  = hoped（应为 hopped）
SFX G 0 ing [^e]   # hop + ing = hoping（应为 hopping）
```

因为 `hop/D` 的存在，查 `hoped` 会同时返回 `hop` 和 `hope` —— 这正是「查 hoped
却出 hop」这个常见抱怨的来源。

## 改了什么

**第一阶段：删除错误标签、补派生链接**

- 删除 **212 个基词上的 438 个错误标签**（D 148、G 154、R 111、T 24、Z 1）；
  真正的同形词保留（`buss/D`、`psych/D,G`、`sky/D`、`putt/G`、`bath/D,G`、`sick/D`）。
- 补回词干链接：`barred/barring → bar`、`cubbed/cubbing → cub`、
  `gapped/gapping → gap`、`snipped/snipping → snip`。
- `halved st:half` / `halving st:half` → `st:halve`（half 不是动词）。
- `sky/R`、`sky/Z` 改挂到 `ski/R`，现在 `skier → ski`。
- 新增 `googleable st:google`（`google/DGSRZB` 只会生成 `googlable`）。
- 给 **2,001 个词条补了 2,169 个派生标签**（`-al`、`-ity`、`-ic`、`-less`、
  `-ful`、`-ish`、`-ness`、`-ly`、`-ive`、`-ion`、`-ions`、`-ings`、`-ment`、`-ous`），
  且只在「派生出来的词本身已是词条」时才加，不会凭空造词。
- `-ic` 的标签用 **`Q`** 而不是 `c`：上游 `.aff` 里已有 `ONLYINCOMPOUND c`，
  挂 `c` 的词会直接从词典里消失。

**第二阶段：合并 ODE 词表**

- ODE 去重后 160,984 条：16,941 条压缩成标签，104,229 条新增为词条，
  总计 **174,422 词条**，体积 866 KB → 2.1 MB。
- 新增后缀/前缀：`-ion`、`-ible`、`-or`、`-ist`、`-ism`、`-ize/-ise`、`-ship`、
  `-hood`、`-dom`、`-ward`、`-ify`、`-ate`、`-ary`、`non-`、`anti-`。
- `WORDCHARS` 加入 `-` 和 `.`，带连字符的 `ortho-axis`、带点的缩写 `a.m.` 可整体匹配。

## 验证

- `hunspell -s` 抽查见 [`tests/cases.txt`](./tests/cases.txt)：`hoped → hope`
  （不再出现 hop）、`hopped → hop`、`skier → ski`、`national → nation`、
  `googleable → google`。
- 回归：原词典 155,082 个词条 + 由原 `.aff` 生成的全部形式，改动前后对比，
  **新增拒绝 = 0**，另有 18 个形式变为可识别。
- ODE 覆盖：159,744 个可收录词条，**0 个被拒绝**。
- 压缩抽样：随机 3,000 对，全部可识别。

## 已知局限

- 专有名词上的 `R`/`Z` 没有动（`Arch/R → Archer`、`Berlin/Z → Berliners`），
  其中不少可能是刻意保留的「地名 → 居民」链接。
- `-al` / `-ity` / `-ic` 带延续类，会让极少数非词被接受（如 `aberrationality`），
  只影响这几个串本身的查询。
- 少量机械压缩在语义上不成立（`arty/Q → artic`、`cray/Q → craic`）。
- ODE 中 1,242 个只作构词成分的条目（`acantho-`、`-acea`）未收录。

## 怎么用

**Ciyue**：设置 → 词形还原 → 打开开关 → 导入本目录 → 查找模式选 **补充
（Supplement）**，这样「变形词」和「原形」会并列显示；选「后备（Fallback）」
则只在所有词典都没有精确词条时才尝试词干。

**GoldenDict / GoldenDict-ng**：把 morphology 目录指向本目录即可。
